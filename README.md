# Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that provides three useful tools through a simple menu.

### Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Even or Odd Checker:** Checks whether a number is even or odd.

## How to Run

1. Open the `toolkit.py` file.
2. Run the program using Python.
3. Choose a tool from the main menu.
4. Follow the instructions displayed.

## Concepts Used

- Variables
- Input and output
- If, elif, and else statements
- For and while loops
- Lists
- Functions
- F-strings

## Reflection

The hardest part of this project was creating the menu loop and connecting all the tools. The most challenging bug was handling invalid user choices. I learned how to use functions to organize my code. I also improved my understanding of loops, lists, and conditionals. Testing each tool helped me understand how the program works. I enjoyed building a practical Python project. With one more week, I would add more tools and improve the program's features.
